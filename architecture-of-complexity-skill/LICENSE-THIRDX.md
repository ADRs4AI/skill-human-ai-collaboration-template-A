## What is Third X?

Third X is a framework for designing LLM-consumable output formats through
linearization and hierarchical structuring. It prioritizes "Model Experience"—
optimizing output for LLM cognition rather than human display—as a core
architectural principle.

The framework emerged from the insight that transformer-based LLMs process
information sequentially, and therefore benefit from linearized, hierarchical
representations over nested data structures.

## More Information

- **Website**: https://thirdx.design
- **Core Principles**:
  - Model Experience: Design for the primary consumer (LLM)
  - Linearization: Sequential text over nested structures
  - Hierarchical IDs: Stable, opaque identifiers
  - Near-decomposability: Weak coupling between output components
